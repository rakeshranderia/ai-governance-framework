# AI Use-Case Assessment

A lightweight pre-implementation assessment for practical AI governance.

## Core model

**Use Case -> Data Classification -> Platform -> Impact -> Controls -> Decision -> Review**

## What this is

A practical decision aid for teams considering whether an AI use case should move into operational use. It connects AI governance to controls organisations already have - particularly data classification, DLP, information security, privacy and acceptable use.

## Key principle

Do not invent a separate data-classification scheme just for AI. Start with the organisation's existing classification and ask whether that class of information is permitted in the proposed AI platform.

If the answer is unclear, consult local IT, Information Security, Privacy or Risk before proceeding.

## Decision outcomes

- Proceed
- Proceed with Controls
- Further Assessment Required
- Do Not Proceed

## What this is not

It is not legal advice, a certification, or a replacement for privacy, security, procurement, records-management or formal enterprise risk processes.
